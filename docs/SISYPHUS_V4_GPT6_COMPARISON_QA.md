# GPT-6 与 GPT-6.1 Sol 的同题对照：V4-GPT6

本分支从 `sisyphus-v4` 派生，保留 V3、V4 原始实现与发布物。用户要求按 **相同原始提示词** 比较 GPT-6 与 GPT-6.1 Sol，不能用不同工具、不同音轨或不同题材造成不公平的胜负结论。

## 共同约束
- 90 秒、720×1280、30fps、完整保留 V3 中文原音轨、哲学观点和 14 个 cue。
- Remotion 4.0.531。V4 作为同一基线，两条路线使用同一段困难镜头与整片。
- 评估维度：几何正确性、动作自然度、旁白动作对应、镜头语义、技术和审片过程、首轮缺陷/修复次数。
- 此分支不是额外的 V5；名称明确为 V4-GPT6，对照 V4/6.1Sol。不能从改进若干处推断总体能力优胜。

## 本轮动作重建
- 独立的 `src/SisyphusV4GPT6.tsx` 和 `src/sisyphusV4GPT6Motion.ts`，未覆盖 V4。
- 修复 V4 的一个可见动作风险：不再把 stance foot 随 gait ease 在人物附近进行附加插值，而是完整使用 foot(s, offset) 推导的固定世界坐标；起停通过人物沿坡进度和上身运动平滑控制。
- 为 16–18 秒增加预备/用力的上身俯倾；17.7–19.65 秒补偿式上身后撤与手部收回，强调松手后的避让；淡色引导线显示落点。
- 保留 V4 原有的正确 SVG 旋转符号、坡面法线、巨石滚动弧长关联、V4 侧方平台和行动分镜。不把已有 V4 的修复冒充 GPT-6 新成果。

## 严格的两阶段流水线与实况
1. 首轮 8 秒（电影原始 16–24 秒，240 帧）：`39037730732` 因遗失 `ascent` import，在 TypeScript 构建失败；修复。
2. 初版样片 `39037803094`：通过独立几何与渲染，采样 0.25 秒连续帧实际人工查看。视觉发现：角色跳到上方平台时上身略像被动坐姿，主动避让的姿态不充分。
3. 加入上身后撤/手臂动作，重渲染第二版样片 `39038051371`，人工检查 contact sheet（32 张）及原生 `full_0.png` / `full_50.png` / `full_60.png` / `full_69.png` / `full_97.png`。可以看到接近、收手、脱离、巨石滚落的顺序；字幕位于下方安全区，石头位移和角度符合物理接触约束。**尚存问题：落地姿态仍略僵硬，视觉风格是符号化火柴人，不是专业人物表演。**
4. 整片流程 `.github/workflows/sisyphus_v4_gpt6_full.yml` 会复用原 V3 视频中的 AAC 音轨，技术 QC 使用 V4 已验证的 `scripts/sisyphus_v4_qc.py`，导出14组0.25秒镜头帧和22个事件逐帧条。**不得将自动 PASS 表述为视觉验收通过。**
