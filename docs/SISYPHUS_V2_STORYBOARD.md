# V2分镜设计：逐句画面叙事合同

**核对源影片后发现：原片35–78s石头位置基本不变；原句18–24s谈滚落但真正滚落从24.5s开始；57–64s谈下落却继续同景推石。这违反画面与旁白同步。V2必须从分镜层面推倒重建。**

##验收底线
- 每句须有 **可辨认、独立于字幕的可视叙事内容**，不能以文字卡或人物平移冒充新信息。
- 必须人工打开 14 个场景代表帧及转场帧，逐句确认字幕与主体动作吻合。
- 尤其18-24s直接看到坠落，57-64s再次看到失控下滑，64-71s看到主动迈步，71-78s看到意识的眼睛特写。
- 画面要有近中远景节奏，哲学论证需视觉化为人与世界之间的意义冲突，而不是永远推一块石头。
- 标准化的ffprobe/像素差异仅是技术QA，绝不能再声称它完成了叙事验收。
