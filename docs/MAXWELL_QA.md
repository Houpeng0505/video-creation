## 难镜头与实际修复

最难的是 13–23 秒的连续筛选：同一批分子保持身份和速度，妖怪先观察，判断后移动实体门板，允许快分子向右、慢分子向左，其他方向保持阻挡。

1. **模拟预演**曾发现门控误判和不希望的尾随通过。修复为根据真实门缝碰撞，开门前预测冲突；分子进入门口时保持足够净空，不以粒子颜色跳过墙体碰撞。
2. **第一版真实样片**的门口快慢标签过密，扫描到开门间隔短。移除逐粒子文字，保留颜色图例、扫描圈和判断牌；拉开观察、判断和开门的阶段，再渲染样片。
3. **首轮全片密集抽帧**发现最后一格没有复位：结束边界使用了严格大于判断。修正结束条件，重新渲染后，62.7 秒起 16 格均为 0。
4. 同一轮发现记忆面板显露时与装置重叠、比特抵达前格子就先显示了记录。调整显露时机，并让飞行比特抵达和写入在同一时刻完成。
5. **原尺寸复核**发现缩小装置时妖怪头部被舞台边界裁切。重排缩放比例和位置，保留头部、能量条与记忆框间距；重渲染 37–63 秒。
6. 最后检查到复位后状态牌仍写“记忆已满”。改为“记忆已满 → 正在复位 → 复位完成”，重渲染 55–63 秒，复查该段的密集抽帧、复位边界和原尺寸完成帧。

两轮完整渲染后，修订段落按精确帧范围重新渲染并重新合成为最终 MP4；没有使用静帧覆盖来掩盖动作问题。

## 仍有不足

- 粒子采用无分子间碰撞的二维理想化运动，会有互相重叠；这是概念演示，不能用于定量热力学结论。颜色只标记速度类别。
- 动能条是有限粒子的平均动能示意，未标定开尔文温度，也没有计算真实气体的熵。分离后的分布不是完整热平衡分布。
- 量子部分只展示测量与反馈的关系，没有展开量子互信息或实验装置；兰道尔公式的小字条件在手机小屏上较小。
- 旁白采用中文 TTS；节奏清楚，但情绪层次仍有限。部分概念通过简化账本和箭头解释，镜头层次还可以继续丰富。
