# 麦克斯韦妖：信息真的能打败熵增吗？

90 秒，720 × 1280，30 fps；中文旁白。与《西西弗斯》各版本使用独立内容、合成组件和输出目录。

## 科学表述边界

- 测量、记录和逻辑不可逆的复位是不同环节；影片没有声称每次测量都必定耗散同样的热。
- `Q ≥ k_B T ln 2` 标注为对称、等概率的一位记忆在等温复位时的平均理想下限。一般记忆、侧信息和非等温协议需要更完整的表述。
- “平均总熵变 ≥ 0”指把控制与信息处理计入后的完整循环；没有对单条微观涨落轨迹作不减承诺。
- 粒子是稀薄理想气体的概念动画，颜色代表速度类别，不代表不同化学物种。能量条不是定量熵测量，也不是以开尔文标定的温度计。
- 信息处理的细节在后半段显露；前半段故意只呈现气体账本，体现思想实验的疑问结构。

## 重现入口

1. 安装仓库锁定的 Node 依赖；Python 音频脚本需要 edge-tts、NumPy，检查脚本需要 Pillow。
2. `python scripts/maxwell_audio.py` 生成 12 段旁白与原创合成配乐；最终音轨含配乐自动压低与响度归一。
3. `node scripts/maxwell_physics_test.cjs` 检查碰撞、门控、速度和能量，写入物理检查报告。
4. 用 Remotion CLI 渲染 `MaxwellDemon`，完整帧范围为 0–2699；样片为 390–689。
5. 合并音轨，转为有限色阶的 H.264/yuv420p 和 AAC，运行 `scripts/maxwell_qc.py`，再实际查看解码帧和视频播放。

音频和渲染都是独立产物；只渲染 Remotion 组件不会自动得到带旁白的成片。
